# Rein Protocol Foundation identity

The mark is a custom vector R: an upright stem, returning loop and forward leg. The orange origin point connects it to the site’s existing international-orange accent. Warm paper (#f5ead3) and ink (#28231f) retain the institutional editorial character.

- `rein-mark.svg`: standalone square brand icon.
- `rein-mark.png`: 1024px export for profiles.
- `app/icon.svg` and `public/favicon.svg`: matching browser icons.
- `app/apple-icon.png`: 180px home-screen icon.
- `components/icons.tsx`: theme-aware inline mark for header and footer.

Keep clear space around the mark and preserve its proportions. The SVG is authored directly for crisp small-size rendering; it is not a raster-generation output.
